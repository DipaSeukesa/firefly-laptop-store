## 📌 Ringkasan Penting bagi Agen AI:

1. **Struktur Dokumentasi Per Halaman**:
   - Seluruh detail setiap halaman aplikasi tersimpan rapi di direktori **[`docs/pages/`](./docs/pages/)**.
   - Indeks master dapat dibaca di **[`docs/README.md`](./docs/README.md)**.

2. **Aturan Keamanan**:
   - **JANGAN upload `.env` ke GitHub.** Gunakan selalu template [`.env.example`](./.env.example).

3. **Standar Keterbacaan & Desain**:
   - Dilarang memakai font mikro (jangan gunakan `text-[7px]` atau `text-[8px]`).
   - Gunakan ukuran minimal `text-xs` (12px) untuk label/badge dan `text-sm` (14px) untuk teks konten.
   - Tombol aksi (Edit, Hapus, Simpan) harus selalu tampak dan nyaman ditekan di layar sentuh HP.

4. **Kompilasi & Build**:
   - Sebelum tugas selesai, selalu jalankan `npm run build` untuk memverifikasi tidak ada error sintaks.

> Untuk pedoman teknis lengkap, silakan merujuk ke dokumen utama: **[AGENTS.md](./AGENTS.md)**.
